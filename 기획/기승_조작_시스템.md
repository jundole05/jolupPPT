# 기승 조작 시스템 기획안

## 핵심 콘셉트

> **말은 운전하는 탈것이 아니라, 신호를 주고받는 파트너다.**

플레이어의 입력은 말에게 보내는 **신호(부조, Aids)** 이며, 말은 자신의 **스태미나와 능력치**에 따라 그 신호에 반응한다.

```
입력(신호) → 말의 스태미나·능력치 반영 → 움직임
```

---

## 1. 조작 요소 (7가지)

### ① 고삐 — 방향과 감속 `A` `D` `S`
- **실제 승마**: 한쪽 고삐로 방향을 틀고, 양쪽 고삐로 속도를 줄인다.
- **게임 구현**: A/D로 좌우 방향 전환, S로 감속. 코너·점프 직전의 속도 조절 수단.

### ② 다리(박차) — 가속 `W`
- **실제 승마**: 종아리로 옆구리를 눌러 전진 신호를 준다.
- **게임 구현**: W를 누르고 있으면 가속하며 스태미나를 꾸준히 소모한다. 계속 몰아붙이면 후반에 지쳐 속도가 떨어진다.

### ③ 자세 — 균형과 속도 `↑` `←` `→` (홀드 방식)
- **실제 승마**: 기수는 무게중심과 자세로 말의 균형을 돕는다.
- **게임 구현**

| 입력 | 자세 | 효과 |
|---|---|---|
| (입력 없음) | **기본 자세** | 균형이 안정적. 장애물 접근·점프·코너에 유리 |
| **↑ 홀드** | **레이싱 자세** (몸을 숙임) | 최고 속도 상승. 균형이 불안정해 코너·점프 시 실수 위험 증가 |
| **← / → 홀드** | **몸 기울이기** | 코너 방향으로 기울이면 속도 손실 감소. 반대로 기울이면 감속하고 휘청임 |

- 키에서 손을 떼면 자동으로 기본 자세로 돌아온다.
- A/D(말의 방향)와 ←/→(기수의 체중)를 함께 맞추는 것이 코너링 실력.

### ④ 보법 모드 — 구보(코너) / 습보(직선) `Left Shift`

| 모드 | 사용 구간 | 특징 |
|---|---|---|
| **구보** | 코너, 장애물 접근 | 회전 안정, 스태미나 소모 적음 / 최고 속도 낮음 |
| **습보** | 직선 | 최고 속도 높음 / 회전 둔함, 스태미나 소모 큼 |

- Left Shift로 두 모드를 전환한다.
- 습보 상태로 코너에 진입하면 크게 밀려나거나 휘청인다.
- 직선에서 습보로 올리고 코너 전에 구보로 내리는 **전환 타이밍**이 핵심 실력.

### ⑤ 리듬 — 말과 호흡 맞추기 (`W`를 박자에 맞춰 입력)
- **실제 승마**: 기수는 말의 걸음 박자에 몸을 맞추며, 리듬이 맞으면 말도 기수도 덜 지친다.
- **게임 구현**
  - 별도 리듬 키 없이 **W를 말발굽 박자에 맞춰 누르면 리듬 가속**이 된다.
  - 리듬 가속: 같은 가속에 스태미나 소모 감소 + 속도 소폭 증가.
  - 박자를 연속으로 맞추면 효과가 커진다(콤보).
  - 박자를 놓쳐도 처벌은 없고 기본 가속과 같은 효과만 난다.
  - 박자는 말발굽 소리와 화면 연출로 표시하며, 구보와 습보는 박자 속도가 다르다.
- 초보자는 W를 꾹 누르기만 해도 레이스가 가능하고, 숙련자는 리듬으로 차이를 만든다.

### ⑥ 점프 — 장애물 넘기 `Space`
- 장애물 앞에서 타이밍을 맞춰 점프한다.
- 결과: 성공(속도 유지) / 타이밍 어긋남(감속) / 크게 실패(넘어짐).
- 말의 **점프력** 능력치가 높을수록 성공 판정 범위가 넓어진다.

### ⑦ 채찍 — 순간 가속 `Tab`
- 레이스당 정해진 횟수(예: 3회)만 사용 가능한 순간 가속.
- 사용 시 스태미나를 한 번에 크게 소모한다.
- 추월·결승 직전 등 **사용 타이밍**이 전략 요소.

## 2. 말의 반응 시스템

### 스태미나 — 레이스 중 변하는 값
- **소모**: W 가속, 습보 주행, 채찍
- **절약**: 구보 주행, 리듬 가속
- **고갈 시**: 최고 속도와 가속이 크게 떨어지고 습보를 유지할 수 없다.
- "언제 달리고 언제 아낄지"를 결정하는 레이스 운영의 중심.

### 능력치 — 육성으로 키우는 고정값

| 능력치 | 영향 |
|---|---|
| **속도** | 습보 최고 속도 |
| **지구력** | 최대 스태미나, 회복 속도 |
| **순발력** | 가속력, 채찍 효과, 모드 전환 속도 |
| **점프력** | 점프 성공 판정 범위, 점프 후 속도 유지 |

- 능력치는 먹이를 통한 육성으로 오르며, 키운 만큼 레이스에서 말이 다르게 움직인다. (상세: `필드_육성_시스템.md`)

---

## 3. 레이스 한 판의 흐름 (예시)

1. **출발** — W로 가속 → Shift로 습보 → ↑ 홀드로 레이싱 자세
2. **직선** — W를 박자에 맞춰 눌러 리듬 가속, 스태미나 절약
3. **코너 진입 전** — ↑에서 손을 떼 기본 자세 → S로 감속 → Shift로 구보 → A/D 방향 전환 + ←/→ 몸 기울이기
4. **장애물** — 기본 자세로 접근 → Space로 점프
5. **마지막 직선** — Shift로 습보 → ↑ 레이싱 자세 → Tab 채찍으로 추월

---

## 4. 조작 난이도 단계

| 단계 | 사용 요소 |
|---|---|
| **입문** | W/S 가속·감속, A/D 방향, Space 점프 |
| **기본** | Shift 모드 전환, 방향키 자세 |
| **숙련** | W 리듬 가속, Tab 채찍 타이밍 |

---

## 5. 키보드 조작표

| 키 | 기능 |
|---|---|
| **W** | 가속 (박자에 맞춰 누르면 리듬 가속) |
| **S** | 감속 |
| **A / D** | 좌우 방향 전환 |
| **Left Shift** | 구보 ↔ 습보 전환 |
| **Space** | 점프 |
| **Tab** | 채찍 (레이스당 횟수 제한) |
| **↑ (홀드)** | 레이싱 자세 (떼면 기본 자세) |
| **← / → (홀드)** | 몸 좌우로 기울이기 |
| **Esc** | 메뉴 (마을에서만) |

- **왼손**: 말 조작 (속도, 방향, 모드, 점프, 채찍)
- **오른손**: 기수의 몸 조작 (자세)
- 레이스 중 지도와 순위표는 화면 UI로 상시 표시하며, 레이스 내부에는 메뉴가 없다.

---

## 6. 기술적 구현 방향

1. **입력 해석 구조** — 입력을 신호로 받아 스태미나·능력치를 반영해 실제 속도, 회전, 점프 판정을 계산한다.
2. **스태미나 시스템** — 행동별 소모·회복량을 관리하고, 잔량에 따라 성능이 저하되도록 한다.
3. **리듬 판정** — 보법별 발굽 박자를 기준으로 W 입력 타이밍을 판정하고 콤보에 따라 효과를 부여한다.
4. **절차적 애니메이션** — 구보·습보 전환 블렌딩, 지형 기반 발 디딤(IK), 자세(레이싱 자세·좌우 기울이기)에 따른 기수의 몸 반응.
